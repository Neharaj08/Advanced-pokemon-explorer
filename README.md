Advanced Pokemon Explorer

A fully-featured React app to explore Pokemon data using the [PokeAPI](https://pokeapi.co/). Users can browse, search, compare, and mark their favorite Pokemon — with pagination, detailed stats, and a sleek UI.

---

Features

- Search Pokemon by name
- Pagination(10 per page)
- Favorites with localStorage persistence
- Compare multiple Pokemon side-by-side
- Detailed View with types, height, and weight
- Routing with React Router
- Error Boundaries for better UX
- Responsive and accessible design

---

Tech Stack

- React
- React Router DOM
- Context API
- PokeAPI
- LocalStorage

---

Setup & Installation

1. Clone the repo
   git clone https://github.com/your-username/pokemon-explorer.git
   cd pokemon-explorer
2. npm install
3.npm start
4.Visit http://localhost:3000
